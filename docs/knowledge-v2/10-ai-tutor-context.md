## 1. Executive Scope & Architectural Guardrail

### 1.1 Post-MVP Boundary Guardrail
> **AI Tutor is strictly DEFERRED from the MVP critical path.**
> It must never be exposed as an active route or required dependency in MVP production deployments.
> However, Knowledge System V2 must be **forward-compatible** with AI Tutor by providing a strictly typed, privacy-preserving context extraction pipeline so that future integration requires zero schema redesign.

### 1.2 The Deterministic-First Separation
The AI Tutor is an **advisory and conversational layer**, never an algorithmic authority.
- The AI Tutor **cannot** calculate FSRS intervals.
- The AI Tutor **cannot** determine curriculum sequencing or modify CEFR placement.
- The AI Tutor **operates strictly downstream**, consuming a sanitized, bounded context envelope generated by the deterministic core.

## 3. Provider Abstraction Interface

To prevent vendor lock-in to OpenAI, Anthropic, or Google Gemini, the AI Tutor service communicates exclusively via an abstract provider interface:

```python
from abc import ABC, abstractmethod
from typing import AsyncIterator
from pydantic import BaseModel

class TutorMessage(BaseModel):
    role: str  # "system", "user", "assistant"
    content: str

class TutorContextEnvelope(BaseModel):
    session_id: str
    context_payload: dict

class AITutorProvider(ABC):
    """Abstract provider for generative conversational tutoring."""

    @abstractmethod
    async def generate_response(
        self,
        context: TutorContextEnvelope,
        history: list[TutorMessage]
    ) -> str:
        """Generate a single completed conversational turn."""
        pass

    @abstractmethod
    async def stream_response(
        self,
        context: TutorContextEnvelope,
        history: list[TutorMessage]
    ) -> AsyncIterator[str]:
        """Stream real-time SSE token response for low-latency client rendering."""
        pass
```

## 4. Guardrails Against Hallucination & Pedagogy Drift

1. **Vocabulary Ceiling**: The prompt generator enforces that the AI Tutor restricts its conversational vocabulary to the learner's verified CEFR band $+ 1$ level (e.g., a B1 learner receives input capped at B2).
2. **Pedagogical Grounding**: Definitions and grammatical formulas provided to the student must be drawn word-for-word from `grammar_specifications` and `word_senses` rather than generated freely by the model.
3. **No Direct Progress Writes**: Chat transcripts do not modify competence scores directly. Only structured quiz interactions triggered by the tutor emit `learning_events` via standard API endpoints.
